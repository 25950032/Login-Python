# 🔐 Sistema de Login en Python

## 📌 Descripción

Este proyecto consiste en un sistema básico de inicio de sesión desarrollado en Python. Permite registrar usuarios e iniciar sesión mediante un nombre de usuario y una contraseña.

El proyecto fue realizado con fines educativos para practicar conceptos fundamentales de programación.

## 🚀 Funcionalidades

- Registro de nuevos usuarios.
- Inicio de sesión.
- Validación de usuario y contraseña.
- Control de intentos fallidos (3 intentos).
- Validación de longitud de contraseña.
- Manejo de opciones incorrectas.
- Menú interactivo.

## 🛠️ Tecnologías y conceptos utilizados

- Python 3
- Diccionarios
- Funciones (`def`)
- Condicionales (`if / else`)
- Ciclo `while`
- Estructura `match-case`
- Validaciones
- `return`

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/TU-USUARIO/Login-Python.git
```

2. Ingresar a la carpeta:

```bash
cd Login-Python
```

3. Ejecutar el programa:

```bash
python login.py
```
